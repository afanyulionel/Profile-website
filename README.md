# Personal Profile Website

This is a responsive, single-page portfolio built for efficiency and simplicity. I designed this as a direct way to showcase my technical skills and professional milestones as I move into my **second year** of engineering.

## 🚀 Overview
The goal of this project was to build a clean, classic-styled site. I prioritized a lightweight layout that serves as a functional professional profile, using a "bookmark" navigation style for smooth, one-page browsing.

## 🛠️ Technical Stack
*   **Languages:** HTML5, CSS3, Python, C, and C++.
*   **Layout Strategy:** Primarily CSS Flexbox with CSS Grid.
*   **Design:** Simplified UI with classic colors and system fonts for maximum performance.
*   **Navigation:** Sticky header with bookmark links for easy section access.

## ✨ Key Features
*   **Efficient Code:** Minimalist approach with no unnecessary libraries.
*   **Note:** Links and interactive elements are styled to be stable (no shrinking or shaking on hover).
*   **Responsive:** Fully functional on mobile and desktop viewports.

## 📂 Project Structure
*   `index.html` - Core structure and content.
*   `style.css` - Custom structural and responsive styling.
*   `assets/` - Directory for profile photos and technical assets.
